# Security Policy

## Supported versions

The project is pre-1.0: only the latest released version receives security fixes.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Use GitHub's [private vulnerability reporting](https://github.com/general03/dispytchr/security/advisories/new)
or email **CONTACT_EMAIL** <!-- TODO: set a public contact address --> with:

- a description of the issue and its impact,
- steps to reproduce (proof of concept if possible),
- the affected version(s).

You will receive an acknowledgement within 7 days. Once the fix is released, the advisory
will be published and you will be credited unless you prefer to stay anonymous.
